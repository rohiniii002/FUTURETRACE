# FUTURETRACE — Explore Your Timelines
Open `index.html` in any modern browser (double-click). No install, no backend, no API key.
Internet is only needed for the Google Fonts; the site works without it using fallback fonts.

- Languages: English / हिन्दी / मराठी (switcher in the navbar, remembered in localStorage)
- Saved timelines are stored in your browser (localStorage)
- To add or fix translations: edit the `X` object in index.html (English text is the key, value is [Hindi, Marathi])
- All scenarios are illustrative, not predictions.
